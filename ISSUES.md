# Issues Management

Este repositorio utiliza los [GitHub Issues](https://github.com/EDINT-Ontologia/edint-ontologia-gestion-residuos/issues) para gestionar incidencias y mejoras sugeridas por la comunidad.

Se recomienda crear un nuevo issue etiquetándolo según su tipo: `bug`, `enhancement`, `question`, o `documentation`. Incluir siempre el contexto, pasos para reproducir (si aplica) y el impacto esperado.
